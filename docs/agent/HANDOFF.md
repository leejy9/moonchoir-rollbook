# 리뷰어(개발계획) 세션 인수인계 — 2026-11-24

> 이전 리뷰어 세션은 클라우드에서 돌아 사용자 컴퓨터의 개발·배포 세션에 메시지를 보낼 수 없었다. 그래서 로컬 세션으로 옮긴다. 새 세션은 이 파일, `AGENTS.md`, `.agents/rules/recurring-mistakes.md`, `docs/agent/SPEC_WRITING.md`를 먼저 읽는다.

## 역할 (사용자 확정)
- 리뷰어(개발계획 세션): 명세·지시서를 쓰고(`spec-writer` 스킬 + `spec-auditor` 검토), 개발 에이전트의 결과를 검토하고, 문제가 없으면 배포 세션에 넘긴다.
- 개발(Sonnet, 중간): 지시서대로 구현하고, 끝나면 리뷰어에게 §5 형식으로 보고한 뒤 멈춘다. 머지·배포는 하지 않는다.
- 배포(Sonnet, 중간): 리뷰어가 넘긴 PR을 병합하고 배포한다.
- 운영 DB 변경은 커밋된 `supabase/migrations/*.sql`만, 적용·검증은 리뷰어(Supabase 커넥터)가 한다. 개발·배포 세션은 SQL을 실행하지 않는다.
