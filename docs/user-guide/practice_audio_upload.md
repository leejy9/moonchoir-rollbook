# 운영진 음원 변환 및 업로드 가이드 (Practice Audio Upload Guide)

Moonchoir Rollbook 연습실에 단원용 파트 음원을 등록하고 관리하는 운영진용 매뉴얼입니다.

---

## ⚠️ 핵심 주의사항 (Strict Rules)
1. **시판 MR·상업 음반 음원은 저작권 보호를 위해 절대 R2 저장소에 직접 파일로 올리지 않습니다.** 시판 음원이나 상용 반주는 반드시 공식 YouTube 링크를 통해 등록해야 합니다.
2. **트랙을 잘못 올렸거나 내용이 변경된 경우, 기존 트랙을 삭제하지 않고 보관(Archive) 처리합니다.** (도메인 불변식: 원천 데이터 보존).

---

## 1단계: 음원 파일을 64kbps AAC (.m4a)로 변환
합창 연습용 음원은 단원들의 모바일 데이터 절약과 끊김 없는 스트리밍을 위해 **64kbps AAC (.m4a)** 포맷으로 변환하여 업로드합니다 (시즌당 20트랙 기준 전체 40~80MB 내외로 압축).

### 무료 변환 도구 활용 방법
특정 유료 프로그램을 구매할 필요 없이, 다음 무료 도구 중 하나를 사용합니다:

1. **무료 오픈소스 오디오 편집기 (예: Audacity)**:
   - 음원 파일을 열고 **파일(File)** → **내보내기(Export)** → **오디오 내보내기**를 선택합니다.
   - 파일 형식을 **M4A (AAC)**로 지정하고, 비트레이트를 **64 kbps**로 설정한 뒤 저장합니다.
2. **무료 터미널 도구 (FFmpeg)**:
   ```bash
   ffmpeg -i input_source.mp3 -c:a aac -b:a 64k output.m4a
   ```
3. **웹 기반 무료 오디오 변환 사이트**:
   - 신뢰할 수 있는 무료 웹 변환기에서 출력 포맷 `M4A/AAC`, 음질 `64 kbps`로 변환하여 다운로드합니다.

---

## 2단계: Cloudflare R2 버킷에 파일 업로드
1. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인합니다.
2. 좌측 메뉴에서 **R2 Storage**로 이동하여 연습실 버킷(예: `moonchoir-music`)을 선택합니다.
3. **Upload** 버튼을 클릭하여 변환된 `.m4a` 파일을 업로드합니다.
4. **객체 키(파일 경로) 명명 규칙**:
   파일 경로는 반드시 다음 규칙에 맞춰 입력하거나 폴더 구조를 생성합니다:
   ```text
   {시즌}/{무작위8자}-{곡명}-{종류}.m4a
   ```
   - **올바른 예시**:
     - `2026-spring/k3f9x2qa-baram-soprano.m4a`
     - `2026-spring/a7b2c9d1-arirang-guide.m4a`
     - `2026-fall/x8y1z2w3-habanera-alto.m4a`
   - *팁: 파일명에 영문 소문자와 하이픈(-)을 사용하면 URL 인코딩 오류를 방지할 수 있습니다.*

---

## 3단계: 관리자 콘솔에서 트랙 등록
1. Moonchoir Rollbook 앱에서 관리자 콘솔(헤더 설정 또는 톱니바퀴 → 관리자 PIN 입력)에 진입합니다.
2. 상단 탭에서 **연습곡** 탭을 선택합니다.
3. 해당 곡의 **트랙 관리** 섹션에서 **트랙 추가**를 클릭합니다.
4. 트랙 정보를 입력합니다:
   - **라벨**: 단원 화면에 표시될 명칭 (예: `소프라노 파트`, `알토 가이드`, `피아노 반주`)
   - **종류**: `파트음원`, `가이드`, `MR`, `참고영상` 등 선택 또는 직접 입력
   - **출처 (Source)**:
     - R2에 올린 음원인 경우: **`R2`** 선택
     - 유튜브 영상인 경우: **`YouTube`** 선택
     - 구글 드라이브 파일인 경우: **`Google Drive`** 선택
   - **경로 또는 URL**:
     - R2 음원: R2 버킷의 객체 키(경로)만 입력 (예: `2026-spring/k3f9x2qa-baram-soprano.m4a`)
     - 유튜브 / 드라이브: 전체 HTTPS 주소 입력 (예: `https://www.youtube.com/watch?v=...`)
5. **재생 방식 미리보기 확인**:
   - 입력란 아래의 미리보기 배너를 확인합니다:
     - `앱 안 재생 가능`: R2 음원으로 정상 스트리밍 재생됨
     - `외부 링크로 열기`: 유튜브 또는 드라이브 링크로 새 창에서 열림
     - `https 주소 아님 / 설정 필요`: 입력값 수정 필요
6. **저장** 버튼을 누르면 즉시 연습실 탭에 반영됩니다.

---

## 4단계: 트랙 수정 및 보관(삭제 불가)
- 음원을 최신 파일로 교체할 때는 이전 파일을 R2에서 덮어쓰지 말고, **새로운 객체 키(새 무작위 8자)로 새 파일을 올린 뒤 트랙의 경로를 변경**합니다 (브라우저 캐시 오염 방지).
- 더 이상 사용하지 않거나 잘못 올린 트랙은 트랙 편집에서 **보관(Archive)** 버튼을 누릅니다. 보관된 트랙은 단원 연습실에서 즉시 숨겨지며, 관리자 화면에서 언제든 복원할 수 있습니다.
