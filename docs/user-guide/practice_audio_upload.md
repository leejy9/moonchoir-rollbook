# 운영진 연습곡 자료 올리기 안내 (v3)

연습실에 단원용 음원·악보·참고 영상을 올리고 관리하는 방법입니다. **모든 작업은 앱의 운영진 화면 → "연습곡" 탭에서 합니다.** Cloudflare 대시보드에 직접 올리거나 파일을 미리 변환할 필요가 없습니다.

> 이전 버전 안내(직접 m4a 변환 → R2 대시보드 업로드)는 v3부터 쓰지 않습니다.

## 지켜야 할 것
1. **시판 MR·상업 음반은 파일로 올리지 않습니다.** 공식 유튜브 링크로 등록합니다(저작권).
2. **잠시 숨길 때는 "보관", 잘못 만든 것은 "삭제"** 합니다. 단원이 이미 들은 기록이 있는 곡·음원은 삭제되지 않고 보관만 됩니다.

## 곡 만들기
1. "연습곡" 탭 → "+ 곡" → 곡 이름(필수)·작곡·편곡 입력.
2. 악보·음원·유튜브 링크를 함께 고른 뒤 **"저장"** 을 누르면 곡이 만들어지고 파일이 올라가기 시작합니다.

## 음원 올리기
- 받는 형식: wav, aiff, flac, m4a, mp3, aac. 파일 하나당 원본 300MB 이하.
- **여러 파일을 한 번에** 고를 수 있습니다(최대 20개). 파일마다 트랙이 하나씩 생기고, 이름은 파일 이름이 기본값입니다. 종류(가이드·MR 등)는 한 번 고르면 전부에 적용되고, 개별 수정은 올린 뒤 트랙에서 합니다.
- 앱이 올리기 전에 **기기에서 자동으로 압축**합니다(64kbps m4a). 직접 변환할 필요가 없습니다.
- "올리기"를 누른 뒤에는 창을 닫아도 계속 올라갑니다. 단, **앱(탭)을 닫으면 멈춥니다.** 진행 상황은 곡 편집 화면의 트랙 줄과 목록 위 칩("올리는 중 n", "실패 n")에 보입니다.
- 저장 공간 사용량은 시트 아래에 표시됩니다(1GB 미만은 MB). 9.5GB를 넘으면 올리기가 막힙니다.

## 악보 올리기
- **PDF만** 받습니다(20MB 이하). 곡마다 1개이며, 새로 올리면 이전 파일을 바꿉니다.

## 대표 음원과 공연 전체 재생
- 곡의 트랙 목록에서 **맨 위 음원이 "대표"** 입니다(목록에 "대표" 표시). 순서를 바꾸면 대표도 바뀝니다.
- 단원이 연습실에서 공연을 고르고 "전체 재생"을 누르면, 공연 순서대로 각 곡의 대표 음원이 이어서 재생됩니다. 음원이 없는 곡(영상만 있는 곡)은 건너뜁니다.

## 공연 관리
- "연습곡" 탭 → "공연"에서 공연(이름·날짜·장소)을 만들고 곡을 연결·정렬합니다. 지난 공연은 숨겨지지 않고 아래로 내려갑니다.

## 문제가 생기면
- "파일 저장소가 아직 연결되지 않았어요": 최고관리자 설정의 파일 저장소 주소를 확인합니다.
- 업로드 "실패": 줄을 누르면 사유가 보입니다. 401이면 다시 로그인한 뒤 "다시 시도"를 누릅니다.
