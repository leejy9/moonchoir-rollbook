# 11. 관리자 [통계] 탭 HR/출결 인사이트 대시보드 기획안

> **작성일**: 2026-10-20  
> **목적**: 다른 작업 환경에서 이어서 개발할 수 있도록, 합의된 관리자 `[통계]` 탭(`AdminStatsTab`)의 구조·지표·데이터 계산식·UI 설계를 상세히 기록한 인수인계 기획 문서입니다.

---

## 1. 배경 및 문제 정의

- **현재 상태 (`src/components/admin/AdminStatsTab.tsx`)**:
  - 기간 칩(`1개월 / 3개월 / 6개월 / 올해 / 전체`) + 파트/상태 필터 + 단원별 체크박스 리스트로만 구성되어 있음.
  - 사실상 `[단원]` 탭(인적사항·출결 매트릭스)의 명단 나열과 중복되며, 임원진(단장·지휘자·파트장·총무)이 한눈에 파악해야 할 **조직 출석 흐름과 단원 케어 인사이트**를 제공하지 못함.
  - 시작일/종료일을 직접 지정해 특정 연주회 시즌이나 반기만 조회하는 기능이 없음.
- **설계 원칙 ("Simple is Best")**:
  - 모바일 화면(가로 100% 폭)에서 글자 줄바꿈이나 빽빽한 설명문 없이 핵심 수치와 시각적 바(Bar) 중심으로 직관적으로 표현한다.
  - 상단 기간 컨트롤러 아래에 **`[요약 인사이트]` (뷰 1)**와 **`[단원별 순위]` (뷰 2)** 세그먼트 탭을 두어 한 화면의 세로 스크롤 과부하를 방지한다.

---

## 2. 화면 구조 및 상세 기능 명세

### 2.1 상단 고정 영역: 기간 설정 바 (프리셋 + 직접 입력)
- **프리셋 칩**: `1개월` | `3개월` | `6개월` | `올해` | `전체` | `직접입력`
- **직접입력(`CUSTOM`) 선택 시**:
  - 하단에 1줄로 `시작일 (YYYY-MM-DD)` ~ `종료일 (YYYY-MM-DD)` 날짜 선택기(`RoundDatePicker` 또는 네이티브 `date` input) 노출.
  - 특정 프로그램 카드(예: `제5회 정기연주회`)의 시작일~종료일만 찍어서 해당 시즌 출석률을 산출할 때 활용.
- **우측 요약 배지**: 해당 기간 내 집계된 **총 연습 횟수(`N회`)** 표시.

---

### 2.2 뷰 1: `[요약 인사이트]` (기본 진입 화면)

임원진이 매주 연습 직후 열어서 **합창단 전체 출석 건강도와 챙겨야 할 단원**을 3초 만에 확인하는 대시보드.

#### ① 전체 핵심 KPI 카드 (3칸 1줄 그리드)
| 지표명 | 표시 형식 | 산출 로직 |
| :--- | :--- | :--- |
| **진행 연습** | `12회` | 선택 기간 내 취소(`isCancelled`)·보관(`isArchived`)을 제외한 과거/당일 유효 일정 수 |
| **평균 출석률** | `86%` | 활동 단원들의 평균 출석률 (`(출석 + 지각) / 필참 모수`) |
| **회당 평균 참석** | `34명` | 기간 내 회차별 실제 출석(`출석 + 수동인정 + 지각` + 자율참석) 인원수의 평균 |

#### ② 파트별 출석률 & 인원 밸런스 (가로 프로그레스 바)
- 동적 파트(`dynamicParts`, 기본: `소프라노 / 알토 / 테너 / 베이스` 등)별로 1줄 가로 바 표시:
  - 좌측: `[파트 배지]` + 활동 인원(`12명`)
  - 중앙: 컬러 프로그레스 바 (`width: ${partRate}%`)
  - 우측: **`88%`** (`평균 10.5명 출석`)
- 어느 파트의 출석률이 떨어지고 있는지 즉시 비교 가능.

#### ③ 인적자원(HR) 케어 보드: 🚨 집중 케어 필요 & 🏆 우수/개근 단원
파트장과 운영진이 가장 자주 쓰는 실무 액션 카드 (탭 또는 좌우/상하 컴팩트 박스):
1. **🚨 케어 필요 단원 (장기 결석 / 저출석 알림)**
   - **추출 조건**:
     - 최근 2회 이상 **연속 무단결석**(`recentStatusList`의 끝에 `'결석'`이 2회 이상 연속) 단원
     - 또는 선택 기간 내 누적 결석 3회 이상 / 출석률 `60% 미만`인 정단원·준단원
   - **표시 정보**: `[파트] 이름 | 연속 2회 결석 (또는 출석률 45% · 결석 3회)`
   - 파트장이 안부 연락을 돌릴 대상을 별도 검색 없이 즉시 확인.
2. **🏆 개근 · 우수 단원 (칭찬/시상용)**
   - **추출 조건**: 선택 기간 내 필참 모수 3회 이상이면서 **출석률 100%(개근)** 또는 최다 출석 상위 단원(자율/게스트 출석 포함).
   - **표시 정보**: `[파트] 이름 | 100% 개근 (12/12회)` 태그 칩 형태로 간결하게 나열.

#### ④ 최근 회차별 출석 추이 (Session Trend List)
- 선택 기간 내 진행된 연습 일정(최근 5~10회차, 더보기 토글 가능)의 회차별 참석 흐름:
  - `10.18 (일) 정기연습` — 가로 미니 바 — **`88% (35/40명)`** `지각 3 · 공결 2 · 결석 3`
  - `10.11 (일) 추가연습` — 가로 미니 바 — **`72% (29/40명)`** `지각 1 · 공결 5 · 결석 6`
- 날씨, 시험 기간, 추가연습 여부에 따른 참여율 변화를 시계열로 파악.

#### ⑤ 단원 구성 현황 (Roster Health Summary)
- 하단 1줄 요약 칩:
  - `전체 N명` (`정단원 N` · `준단원 N` · `휴단원 N` · `선생님/객원 N`)

---

### 2.3 뷰 2: `[단원별 순위]` (개별 단원 상세 조회 & 비교)

기존의 무거운 체크박스 명단을 **100% 가로폭 1줄 아코디언 리스트**로 경량화한 화면.

#### ① 상단 필터 & 정렬 바
- **파트 필터 칩**: `전체 | 소프라노 | 알토 | 테너 | 베이스 ...`
- **상태 필터 칩**: `전체 | 정단원 | 준단원 | 휴단원 ...`
- **검색창 + 정렬 드롭다운 (1줄)**:
  - 검색: 이름/특이사항 검색
  - 정렬(`SortOption`): `출석률 높은순` / `출석률 낮은순` / `결석 많은순` / `지각 많은순` / `이름순`
  - 우측 `[비교]` 토글 버튼: 평소에는 체크박스를 숨기고, `[비교]` 버튼을 눌렀을 때만 다중 선택 체크박스와 상단 비교 카드를 노출.

#### ② 단원 1줄 아코디언 행 (Default Collapsed Row)
- **기본 1줄 표시**:
  - `[파트 배지] 이름 [개근/주의 배지]` ··· 우측 **`92%`** `(출석 11 · 결석 1) ▾`
- **터치 시 아코디언 펼침 (Expanded Detail)**:
  - 세부 횟수: `필참 모수 12회 | 출석 10 · 지각 1 · 사유결석(공결) 0 · 무단결석 1` (+ 자율/게스트 참석 `N회`)
  - 최근 5회 출결 흐름: 최근 5회 연습의 날짜와 상태(`출석 / 지각 / 공결 / 결석`) 컬러 도트 및 라벨
  - 입단일(`joinedAt`) 및 관리자 특이사항 메모(`note`)

## 3. 수정 대상 파일 및 구현 레시피 (4단계)

다른 환경에서 작업을 바로 시작할 때 아래 순서대로 진행하면 됩니다:

1. **`src/hooks/useAttendanceAdmin.ts` 확장**:
   - `PeriodOption`에 `'CUSTOM'` 추가 (`customStartDate`, `customEndDate` 상태 추가 및 `getPeriodRange`에 반영).
   - `cumulativeSessions`와 `memberSummaries`를 바탕으로 아래 파생 통계(`statsInsights`)를 `useMemo`로 계산하여 반환:
     - `overallAvgRate` (전체 평균 출석률)
     - `avgAttendeesPerSession` (회당 평균 출석 인원)
     - `partBreakdown`: 파트별 활동 인원, 평균 출석률, 회당 평균 출석자 수
     - `sessionTrends`: 각 연습 회차별 `{ scheduleId, date, title, category, targetCount, attendedCount, lateCount, excusedCount, absentCount, rate }`
     - `careNeededMembers`: 최근 2회 연속 결석 또는 출석률 60% 미만 단원 배열
     - `perfectAttendanceMembers`: 출석률 100% 개근 단원 배열
2. **`src/components/admin/AdminStatsTab.tsx` 개편**:
   - 상단 기간 바에 `직접입력` 날짜 피커 연결.
   - 내부 서브탭 `statsSubView: 'INSIGHTS' | 'RANKING'` 상태 추가.
   - `INSIGHTS` 뷰: KPI 3칸 카드 + 파트별 프로그레스 바 + 케어/개근 보드 + 회차별 추이 리스트 렌더링.
   - `RANKING` 뷰: 정렬 드롭다운 + 1줄 아코디언 단원 리스트 + `[비교]` 토글 모드 렌더링.
3. **`src/components/AdminDashboard.tsx` 연결**:
   - `useAttendanceAdmin`에서 추가된 `customStartDate`, `customEndDate`, `statsInsights` props를 `AdminStatsTab`에 전달.
4. **단위 테스트 검증 (`src/components/admin/AdminStatsTab.test.tsx`, `src/hooks/useAttendanceAdmin.test.tsx`)**:
   - 직접입력 기간(`CUSTOM`) 필터링 정확도 테스트.
