## 1. 플레이어 조작

| 버튼 | 동작 |
|---|---|
| 5초 뒤로 | `currentTime = max(0, t − 5)` |
| 5초 앞으로 | `currentTime = min(duration, t + 5)` |
| 재생 속도 | 버튼을 누르면 속도 시트가 열린다(아래 1-1). 마지막 선택을 기기에 기억(localStorage, 실패 시 1.0). `preservesPitch = true` 유지 |
| 한 곡 반복 | 켜짐/꺼짐. 꺼져 있으면 끝에서 정지(자동으로 다음 음원으로 넘어가지 않음) |
| 미니 바 | 아래로 밀면 닫힘(재생 정지), 탭하면 전체 화면 |
| 잠금 화면 | Media Session API에 `seekbackward`/`seekforward`를 5초로 등록 |

### 1-1. 재생 속도 시트 (제안)

- 범위 0.5x ~ 2.0x, 0.05 단위. 네이티브 `<input type="range">` 사용(라이브러리 없음).
- 1.0 근처(±0.03)에서 1.0으로 붙는다(snap).
- 슬라이더 양옆에 −0.05 / +0.05 버튼(44px)을 둔다. 손 떨림 없이 미세 조정하기 위해서다.
- 아래에 프리셋 칩 4개: 0.75 / 1.0 / 1.25 / 1.5.
- 원형 다이얼은 쓰지 않는다. 이유:
  - 전체 화면 플레이어의 "아래로 밀어 닫기" 제스처와 충돌한다.
  - 정확한 값(1.0)을 맞추기 어렵다.
  - 스크린리더 지원을 따로 만들어야 한다.
- 음 높이 유지 토글은 만들지 않는다(A10). 브라우저 기본값을 건드리지 않는다.

### 1-2. 유튜브 바로가기 (A9)

- 연습실 곡 목록 상단: 운영진이 등록한 **재생 목록 버튼**(0~3개, 예: "이번 학기 참고 영상").
- 곡 상세의 유튜브 항목: 임베드 옆에 "유튜브에서 열기" 버튼.
- 링크는 `https://www.youtube.com/playlist?list=…` / `https://www.youtube.com/watch?v=…`(또는 `youtu.be`) 원문 그대로 연다. `target="_blank" rel="noopener"`.
  - 휴대폰에 유튜브 앱이 있으면 대부분 앱으로 열린다.
  - 홈 화면 앱(PWA)에서는 기기에 따라 브라우저로 열릴 수 있다. 실기기 테스트 항목에 넣는다.
- 저장 위치: 재생 목록은 공개 설정(`app_config`, 비밀 아님)에 `{ title, url }[]`로 둔다. 관리 화면은 운영진 토큰이 필요하다.
- 입력 검증: 호스트가 `youtube.com`, `www.youtube.com`, `m.youtube.com`, `music.youtube.com`, `youtu.be`인 `https` URL만 허용한다.

유튜브 임베드는 이 플레이어를 쓰지 않는다(유튜브 자체 컨트롤). 백그라운드 재생 불가는 그대로.

## 2. 출석 기록 필터

- 상단 4개 카드는 토글 버튼(`aria-pressed`). 한 번 누르면 그 상태만, 다시 누르면 전체.
- 한 번에 하나만 선택된다. 기간 칩(최근 3개월 / 올해 / 전체)과 함께 적용된다.
- 카드 숫자는 선택한 기간 기준이다.
- 지각 행에는 **시작 시각과 체크인 시각**을 같이 보여준다(왜 지각인지 바로 알 수 있도록).
- 결과가 0건이면 빈 목록과 함께 "이 기간에는 없어요" 한 줄만 보여준다.

### 상태 분류 (하드코딩 금지 규칙과의 연결)

출결 상태 이름은 관리자가 바꿀 수 있으므로(AGENTS.md §1), 계산은 **상태 이름이 아니라 분류**로 한다.
설정에 상태별 분류를 둔다.

| 분류 키 | 기본 매핑 예시 | 카드 |
|---|---|---|
| `present` | 출석 | 출석 |
| `late` | 지각 | 지각 |
| `excused` | 병가, 공가, 사유 | 사유 결석 |
| `absent` | 결석, 무단 | 결석 |
| (미분류) | 관리자가 새로 만든 상태 중 분류를 안 정한 것 | 카드에서 제외, 목록 "전체"에서만 원문 표시 |

미분류 상태도 원문 그대로 보존·표시하고, 스티커·온도 계산에서는 **중립(0)**으로 다룬다.

## 3. 칭찬 스티커 24개 (초안)

원칙

- 원천 로그(출석 체크인, 투표 이벤트, 연습실 사용 요약)에서 **매번 계산**하는 투영 값이다. 별도 "획득" 테이블을 두지 않는다.
- 조건을 처음 만족한 날짜를 획득일로 보여준다.
- 새로 얻은 스티커 알림(한 번만)은 기기별 "본 목록"을 localStorage에 둔다. 비어 있으면 알림만 다시 뜰 뿐 데이터는 안전하다.
- 깎이는 스티커는 없다. 다만 운영진이 원천 기록을 정정하면 재계산 결과가 달라질 수 있다.
- 잠긴 스티커도 이름은 보인다(무엇을 하면 되는지 알도록).

## 4. 열정 온도 계산 (초안)

### 4-1. 원칙

1. **투영 값**이다. 저장된 잔액을 더하고 빼지 않고, 볼 때마다 원천 로그로 다시 계산한다. 규칙을 바꿔도 원천 데이터는 그대로다.
2. **최근 기록만** 본다. 오래 전 실수가 영원히 남지 않게 한다.
3. **모든 변화에 이유 한 줄**이 붙는다(시안의 내역 시트). 이유 없이 움직이는 숫자는 없다.
4. 지각은 감점이 아니라 **0**이다. 사유 결석(병가·공가)도 **0**이고 연속 기록을 끊지 않는다.
5. 본인만 본다.

### 4-2. 계산 창

- **대상 일정:** 최근 12회. 본인이 참석해야 했던 일정, 즉 출결 기록이 있거나 참석 투표를 한 일정만 센다. 입단 전 일정은 제외한다.
- **공연:** 최근 12개월 안의 공연 분류 일정만 본다.
- 12회가 안 되는 신입은 있는 만큼만 계산한다(기본값 36.5에서 시작).

### 4-3. 항목과 점수

| 묶음 | 항목 | 점수 | 상한 |
|---|---|---|---|
| 출석 | 시작 전 체크인 1회 | +0.10 | — |
| | 시작 10분 전 이전 체크인 1회(위에 더해서) | +0.05 | — |
| | 현재 정시 연속 5회 이상 | +0.30 | 하나만 적용 |
| | 현재 정시 연속 10회 이상 | +0.60 | 〃 |
| | 지각 | 0 | — |
| | 사유 결석 / 미분류 | 0 | — |
| | 무단 결석 1회 | −0.40 | — |
| 약속 | 24시간 전까지 투표 1회 | +0.05 | +0.60 |
| | 약속 지킴률 90% 이상 | +0.30 | 하나만 적용 |
| | 약속 지킴률 75~90% | +0.10 | 〃 |
| | 참석 투표 후 무단 결석(노쇼) | −0.50 | 무단 결석 −0.40을 **대체**(중복 감점 없음) |
| | 시작 3시간 이내 참석→불참 변경 | −0.10 | — |
| 공연 | 공연 출석 1회 | +0.20 | +0.60 |

- **최종값:** `36.5 + 합계`. 범위는 34.0~42.0으로 자르고 소수 첫째 자리까지 보여준다.
- **"이번 주 ±x"** = 오늘 값 − 7일 전 시점 값. 같은 규칙으로 7일 전 기준으로 계산한다.
- **최댓값 예시:** 12회 모두 10분 전 도착(+1.8) + 연속 10회(+0.6) + 빠른 투표(+0.6) + 지킴률(+0.3) + 공연 3회(+0.6) = +3.9 → 40.4°C. 42.0은 사실상 닿지 않는 여유 범위다.
- **투표 로그가 쌓이기 전:** 약속 묶음은 숨긴다. 출석·공연만으로 계산한다.

### 4-4. 내역 시트 표시 규칙

- 묶음(출석 / 약속 / 공연)별로 0이 아닌 항목만 보여준다. 단 지각은 "지각 n회 · 0"으로 표시해 감점이 아님을 알린다.
- 항목 문구에는 횟수를 넣는다. 예: "일찍 도착 3회 +0.15".
- 각 항목을 누르면 해당 일정 목록이 나온다(출석 기록 필터 화면 재사용).

### 4-5. 테스트로 고정할 것 (개발 지시서에 옮길 때)

- 19:30 시작에 19:30:59 체크인 → 정시, 19:31:00 → 지각
- 지각만 있는 12회 → 36.5
- 사유 결석이 끼어도 정시 연속이 유지됨
- 노쇼 1회 = −0.5(−0.9 아님)
- 상한 항목들이 상한을 넘지 않음
- 미분류 상태 → 0, 원문 보존
- 같은 원천 로그 → 항상 같은 값(결정적)

## 5. 스티커 시각 디자인 방향 (A8)

공개 디자인 자산을 조사한 결과다(2026-11-21).

| 자산 | 라이선스 | 판단 |
|---|---|---|
| Microsoft Fluent Emoji (3D) | MIT로 알려짐. 상표 이모지(Clippy 등)는 제외 | **추천.** 입체감 있는 스티커 느낌이고 수정(잠김 상태 흑백 처리 등)이 자유롭다. 반영 전 공식 저장소 `microsoft/fluentui-emoji`의 LICENSE 원문을 확인한다. |
| 토스페이스 | 자체 라이선스. 사용·재배포는 무료, **변형(2차 저작물) 금지** | 비추천. 잠긴 스티커를 흑백으로 바꾸는 것도 변형에 해당할 수 있다. |
| 일반 배지 아이콘 팩 | 대부분 유료 또는 CC-BY(출처 표기) | 비추천. 품질과 라이선스가 제각각이다. |

구성안

- 스티커 1개 = **우리 프레임** + 가운데 Fluent 3D 이모지.
  - 프레임은 묶음별로 모양과 색을 다르게 한다.
  - 단계형(10/50/100회 등)은 테두리 색을 동·은·금으로 나눈다.
- 잠긴 스티커는 같은 그림에 흑백과 투명도를 적용하고 이름은 보인다.
