# 13. 관리자 일정 화면 재설계 (PC 기준) — 합의 기록과 개발 계획

> **작성일**: 2026-10-23
> **상태**: 기획 단계. 아래 `합의 사항`은 소유자가 대화에서 직접 고른 것이고, `제안`·`남은 질문`은 아직 합의되지 않았습니다. 코드는 아직 바꾸지 않았습니다.

## 1. 배경

- 지금 `일정` 탭은 `캘린더` / `일정`(목록) / `카드` / `QR` / `출결`로 나뉘어 같은 일정에 대한 일이 흩어져 있고, 목록은 모든 줄이 같은 모양이라 상태를 알려면 펼쳐야 한다. 일괄 수정은 오른쪽 위 `선택` 버튼 뒤에 숨어 있다.
- 사용 실태(소유자): **일정 관리는 PC에서, 폰은 급할 때만.** 한 달 일정 4~8개. 연습 장소를 전부 바꾸는 일이 종종 있고, 4주 중 2개만 바꾸는 일도 있다. `카드` 묶음으로 일괄 처리하려던 것은 맞지 않았다. 정기연습은 시리즈로 묶어 보이고 지난 일정은 가린다.

## 2. 합의 사항 (소유자 선택, 2026-10-23)

1. **뼈대**: 왼쪽 = 작은 월 달력 + 그 아래 `시리즈` 목록, 오른쪽 = 선택한 날짜·일정의 패널.
2. **일괄 수정**: 시리즈를 펼치면 회차마다 체크칸, 시리즈 줄에 `이후 모두 선택`. 체크하면 오른쪽 패널이 `N개 일정 일괄 수정`으로 바뀐다(바꿀 항목만 체크해 반영 — 기존 방식 유지, 항목에 참석 대상·공개 범위 추가).
3. **패널 순서**: 위에서부터 일정 요약 → 사전 투표·출석 현황(숫자 + 이름 목록 펼치기) → 작업 버튼 → `설정 수정`(접힘, `저장`으로 확정).
4. **새 일정 만들기**: 오른쪽 패널에서. 빈 날짜를 누르거나 `+ 일정 등록`을 누르면 패널이 새 일정 폼이 되고 날짜가 미리 채워진다. 한 번 / 매주 반복 / 날짜 여러 개 선택도 같은 폼 안에 둔다.
5. **카드(시즌 묶음)**: 화면에서만 숨기고 데이터는 보존한다(시트의 카드 탭·`programId` 열 유지). 시즌 복제는 시리즈 메뉴의 `다음 기간으로 복제`로 남긴다.
6. **같은 날 일정이 둘 이상**: 패널 맨 위에 시간 탭(`10:00 추가연습` `14:00 결혼식 축가`). 일정이 하나면 탭은 숨긴다.
7. **지난 일정**: 시리즈의 지난 회차는 `지난 회차 N개`로 접고, 끝난 시리즈는 맨 아래 `지난 일정 보기`에서만 본다. 달력의 지난 날짜는 흐리게 보이되 눌러서 출결 기록을 볼 수 있다. `보관`은 `⋯` 메뉴(복제·보관·취소·삭제)로 옮긴다.
8. **QR·출결**: 벽에 붙이는 상설 QR은 출력해 두므로 자주 볼 필요가 없어 **설정의 출력용 메뉴**로 옮긴다. 일정별 출결 명단과 수동 출석 처리는 패널의 `출결 보기`에서 펼친다.
9. **현장 PIN**: 합창단 공용 PIN 하나(2026-10-20 합의 유지). 각 일정 패널에서 현재 PIN을 보고 `새로 발급`할 수 있으며, 발급 즉시 모든 일정에서 새 PIN이 유효하다.

## 3. 제안 (아직 합의 전)

- 시리즈 묶음의 기준은 일정에 이미 있는 `seriesId`·`seriesIndex`·`seriesTotal`을 쓴다(새 열 없음). 시리즈가 아닌 일정은 `단발 일정` 묶음으로 보인다.
- 일괄 수정 패널에는 기존 `복제` `보관` `취소` `삭제`도 함께 둔다.
- 폰(좁은 화면)에서는 한 열로 쌓고(달력 → 시리즈 → 패널은 아래에서 올라오는 시트), PC 구성을 먼저 만든다.
- 같은 수정 패널을 `달력`과 `시리즈` 어느 쪽에서 눌러도 쓴다.

## 4. 남은 질문

1. 달력 칸에 같은 날 일정이 여러 개일 때 점 여러 개로 충분한가, 제목 일부도 보여줄까.
2. 일괄 `삭제`·`취소`를 반복 일정 전체에 쓸 때 확인 절차를 어디까지 둘까.
3. `이후 모두 수정`에서 이미 출석 기록이 있는 지난 회차는 항상 제외하는가.
4. 폰 화면의 우선순위(급할 때 하는 일이 무엇인지): 수동 출석, 취소, PIN 확인 중 무엇이 가장 급한가.

## 5. 개발 순서 (제안)

1. 시안(클릭해 볼 수 있는 화면)으로 배치 확인 → 소유자 확정
2. 일정 화면 뼈대(달력 + 시리즈 목록 + 오른쪽 패널), 현황 패널, 새 일정 폼
3. 시리즈 체크 + 일괄 수정 패널(공개 범위·대상 포함)
4. 카드 탭·QR 탭·출결 탭 정리, 상설 QR 출력 메뉴를 설정으로 이동
5. 폰 화면 대응

각 단계는 `typecheck`·`lint`·`test` 통과와 화면 캡처 확인 후 보고한다. 시트 스키마는 바꾸지 않는다.
