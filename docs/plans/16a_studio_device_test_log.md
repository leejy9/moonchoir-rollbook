## 3. 테스트 진행 안내 및 체크 표시법

- **결과 표기**:
  - `PASS`: 정상 작동함
  - `FAIL`: 재생 중단, 소리 안 남, 컨트롤 오류 등 비정상 동작 발생 (비고란에 상세 증상 기재)
  - `N/A`: 해당 기기 또는 브라우저에서 지원하지 않거나 테스트 불필요
  - `대기`: 테스트 미수행 상태
- **iOS 홈 화면 PWA 주의사항**:
  - WebKit 198277/295518 버그로 인해 iOS 홈 화면 앱에서는 백그라운드 전환 시 오디오가 일시 정지될 수 있습니다.
  - 이 경우 상단 안내 배너의 "Safari에서 열기"를 통해 브라우저에서 정상 백그라운드 재생이 가능한지 비교 검증합니다.
